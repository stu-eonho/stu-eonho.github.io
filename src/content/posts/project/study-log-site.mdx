## 왜 만들었나

읽은 논문 메모가 노트 앱, 문서, 메신저에 흩어져 있어 다시 찾기가 어려웠습니다. 검색 가능한 한곳에 쌓되, 운영 부담은 0에 가깝게 두고 싶었습니다.

## 어떻게 만들었나

- 콘텐츠는 리포지토리의 Markdown 파일 하나가 진실 공급원입니다
- 카테고리는 설정 배열의 항목 하나로 추가됩니다 — 라우트 파일을 만들지 않습니다
- 검색은 빌드 산출물을 인덱싱하는 정적 전문 검색을 씁니다

```bash
npm run build && npm run preview
```

## 무엇을 배웠나

기능을 더하는 것보다 **넣지 않기로 정한 것**을 문서에 남기는 편이 나중에 더 도움이 됐습니다.
