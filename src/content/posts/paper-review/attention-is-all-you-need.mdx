## 한 줄 요약

순환과 합성곱을 모두 걷어내고 어텐션만으로 시퀀스 변환을 수행해도, 번역 품질과 학습 속도를 동시에 얻을 수 있다는 것을 보인 논문입니다.

## 배경

RNN 계열은 시퀀스를 순서대로 처리하기 때문에 시점 방향의 병렬화가 불가능합니다. 문장이 길어질수록 학습 시간이 선형으로 늘고, 먼 위치 사이의 의존을 학습하려면 그만큼 많은 단계를 거쳐야 합니다.

## 방법

핵심은 scaled dot-product attention입니다.

$$
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

$\sqrt{d_k}$로 나누는 이유는 차원이 커질수록 내적 값의 분산이 커져 softmax가 포화되기 때문입니다.

### 멀티헤드

하나의 어텐션으로 모든 관계를 담는 대신, 표현 공간을 $h$개로 쪼개 각각 어텐션을 계산하고 다시 이어 붙입니다.

```python
import torch


def scaled_dot_product_attention(q, k, v, mask=None):
    scores = q @ k.transpose(-2, -1) / (k.size(-1) ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    return scores.softmax(dim=-1) @ v
```

### 위치 인코딩

어텐션 자체에는 순서 개념이 없으므로 위치 정보를 따로 더해 줍니다.

| 방식             | 장점                 | 단점                                 |
| ---------------- | -------------------- | ------------------------------------ |
| 사인·코사인 고정 | 학습 파라미터가 없다 | 길이 외삽이 제한적                   |
| 학습형 임베딩    | 데이터에 맞춰진다    | 학습 길이를 넘어서면 정의되지 않는다 |
