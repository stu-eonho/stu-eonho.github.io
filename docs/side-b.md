# Side B 채우기

Side B는 좋아하는 노래와 앨범을 커버 카드로 모아 두는 작은 탭입니다. 이름은 레코드의 B면에서
왔습니다 — 공부 기록이 A면이고 이 탭이 B면입니다.

| 언어   | 주소         |
| ------ | ------------ |
| 한국어 | `/side-b`    |
| 영어   | `/en/side-b` |

**헤더 메뉴에는 없습니다.** 6번째 항목을 넣으면 768~900px 폭에서 사이트 이름이 잘려서 뺐습니다.
대신 레코드 아이콘(`disc-3`) 링크가 두 곳에 있습니다.

- 홈 프로필 카드의 소셜 아이콘 줄 끝
- 푸터 아이콘 줄(RSS 앞)

`MUSIC`이 비어 있으면 페이지는 "아직 담긴 음악이 없습니다" 안내만 보여 주고, 두 링크도 함께 숨습니다.

## 관리자로 채우기 (권장)

`npm run admin` 후 사이드바의 **Side B**(`/admin/side-b`)를 엽니다.

1. **곡·앨범 추가**로 행을 만들고 종류·제목·가수를 적습니다. 앨범 칸은 종류가 "노래"일 때만 보입니다.
2. 커버 이미지를 드롭존에 놓습니다. 썸네일이 뜨면 올라간 것입니다.
   **올라가는 동안에는 저장이 막힙니다** — 저장할 때 도는 커버 정리가 방금 올린 파일을 지우지 않게 하기 위해서입니다.
3. 장르는 Enter로 하나씩 넣습니다. 이미 쓴 장르가 제안 목록에 나옵니다.
4. 좋아하는 이유와 듣기 링크를 적고 **저장**합니다. 링크 칸 옆에 `→ Spotify` 같은 판정 결과가 보입니다.

화면 위의 버튼으로 `/side-b`·`/en/side-b`를 새 탭에서 바로 확인할 수 있습니다.

## 파일로 직접 쓰기

데이터는 `src/config/music.ts`의 `MUSIC` 배열입니다. **위에서 아래 순서가 화면 순서입니다.**

```ts
export const MUSIC: MusicEntry[] = [
  {
    kind: 'album', // 'song' | 'album'
    title: '○○ 앨범', // 원어 그대로 — 번역하지 않습니다
    artist: '○○',
    year: '2024', // 네 자리. 생략 가능
    cover: 'album-cover.jpg', // src/assets/side-b/ 안의 파일명. 생략 가능
    genres: ['Indie Rock', 'Dream Pop'],
    note: { ko: '좋아하는 이유', en: 'Why I love it' }, // 언어별 140자. 문자열 하나도 됩니다. 생략 가능
    listenUrl: 'https://open.spotify.com/album/…', // 생략 가능
  },
  {
    kind: 'song',
    title: '○○',
    artist: '○○',
    album: '○○ 앨범', // 노래일 때만. 생략 가능
    genres: [],
  },
];
```

커버 파일은 `src/assets/side-b/`에 넣습니다. `jpg`·`jpeg`·`png`·`webp`·`avif`·`gif`가 파일명을 키로 자동으로 잡힙니다.
**확장자는 소문자여야 합니다** — `.JPG`는 잡히지 않아 대체 커버가 나옵니다. 정사각형을 권장합니다.

> **dev 서버에서 커버가 대체 커버로 남아 있을 때**
>
> 관리자 콘솔이 켜진 dev 서버는 `src/assets/side-b/`에 **새 파일이 생기는 이벤트를 무시합니다.**
> 커버를 올릴 때마다 열린 탭이 전부 새로고침되어 관리자 화면의 입력이 사라지던 것을 막는 장치입니다.
> 그래서 손으로 복사하거나 `git pull`로 커버가 들어올 때, `music.ts`가 **먼저** 바뀌고 커버 파일이
> **나중에** 도착하면 dev 사이트가 그 카드를 대체 커버로 계속 보여 줄 수 있습니다.
> `music.ts`를 한 번 더 저장하거나 dev 서버를 껐다 켜면 잡힙니다. 빌드에는 영향이 없습니다.

## 필드 규칙

관리자 저장이 아래 규칙을 검사하고, 어긋나면 그 칸에 오류를 띄우며 저장하지 않습니다.
파일을 직접 고치면 이 검사를 거치지 않으므로, 사이트는 깨지지 않는 쪽으로만 대처합니다(오른쪽 열).

| 필드        | 관리자 저장                                                                | 파일을 직접 고쳤을 때                                      |
| ----------- | -------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `title`     | 비면 그 행을 버립니다                                                      | 비면 화면에 나오지 않습니다                                |
| `album`     | `kind: 'song'`일 때만 남깁니다                                             | 노래가 아니면 표시하지 않습니다                            |
| `year`      | `YYYY` 네 자리만 받습니다                                                  | 적은 그대로 표시됩니다                                     |
| `cover`     | `src/assets/side-b/`에 있는 파일명만 받습니다                              | 파일이 없으면 빌드 경고 후 대체 커버(제목 첫 글자)         |
| `genres`    | 빈 값을 버리고, 대소문자·앞뒤 공백만 다른 표기는 처음 표기 하나로 합칩니다 | 같은 규칙으로 한 장르로 봅니다                             |
| `note`      | **언어별 최대 140자**                                                      | 길이를 검사하지 않습니다 — 넘치면 뒷면 안에서 스크롤됩니다 |
| `listenUrl` | `http(s)`만 받습니다. 스킴 없이 적으면 `https://`를 붙여 저장합니다        | `http(s)`가 아니면 빌드 경고 후 링크를 생략합니다          |

- 장르는 카드 뒷면에 최대 3개까지 보이고, 필터 줄에는 전부 나옵니다. 필터 칩은 많이 붙은 장르가 앞에 옵니다.
- `note`는 한 값으로 쓰거나 `{ ko, en }`으로 나눕니다. 한쪽만 채우면 다른 언어 화면에서도 그 값을 씁니다.

140자 제한은 뒷면이 정사각형이라 둔 것입니다. 260px 카드에서 140자 이유·장르 3개·듣기 링크가 함께 있어도
뒷면이 스크롤되지 않습니다.

듣기 링크의 라벨은 주소의 호스트로 정해집니다.

| 호스트                    | 라벨                   |
| ------------------------- | ---------------------- |
| `youtube.com`, `youtu.be` | YouTube에서 듣기       |
| `music.youtube.com`       | YouTube Music에서 듣기 |
| `open.spotify.com`        | Spotify에서 듣기       |
| `music.apple.com`         | Apple Music에서 듣기   |
| `melon.com`               | Melon에서 듣기         |
| 그 밖                     | 듣기                   |

## 커버 정리 — 이 폴더에 다른 파일을 두지 마세요

관리자에서 Side B를 **저장할 때**, `src/assets/side-b/` 안에서 저장된 어떤 항목도 참조하지 않는
이미지 파일을 지웁니다. 커버를 바꾸면 옛 파일이 따라서 사라지는 이유입니다.

- 자동 삭제는 이 폴더에만 일어납니다. 글 본문 이미지(`src/assets/` 최상위)는 건드리지 않습니다.
- 지우는 대상은 업로드가 허용하는 이미지 확장자 파일뿐입니다.
- 저장이 실패하면(검증 오류, 다른 곳에서 파일이 바뀜) 아무것도 지우지 않습니다.
- 관리자의 "이미지" 화면(`/admin/assets`)에는 이 폴더가 보이지 않습니다. 그 화면에서 커버를
  지워 빌드가 깨지는 경로를 없애려고 하위 폴더로 나눴습니다.

## 화면에서 하는 일

- **카드를 누르면** 오른쪽 아래 모서리가 들리며 대각선으로 뒤집힙니다. 뒷면에는 제목·가수·장르·이유·듣기 링크가 있습니다.
- **마우스를 올리면** 커버가 포인터를 따라 최대 6° 기울어집니다. 터치 화면에서는 기울지 않습니다.
- **장르 칩을 누르면** 그 장르의 카드만 남습니다. 같은 칩을 다시 누르면 "전체"로 돌아갑니다.
  고른 장르는 주소에 `#genre=indie%20rock`처럼 남아 새로고침하거나 공유해도 같은 필터로 열립니다.
  장르가 하나도 없거나 카드가 2장 미만이면 필터 줄이 나오지 않습니다.
- **모션 줄이기**를 켜면 기울지 않고, 뒤집기와 필터는 회전·페이드 없이 즉시 바뀝니다.
- **JavaScript가 없으면** 필터 줄이 나오지 않고, 각 카드의 뒷면 정보가 앞면 아래에 펼쳐져 보입니다.
- 사이트 검색과 RSS에는 나오지 않습니다.

이 화면의 스크립트는 Side B 페이지에만 실립니다. 다른 페이지의 JavaScript는 늘지 않습니다.

## 비웠을 때 어떻게 되나

| 비운 항목       | 화면                                                  |
| --------------- | ----------------------------------------------------- |
| `MUSIC` 전체    | 빈 상태 안내만 나오고, 홈·푸터의 진입 링크가 숨습니다 |
| `cover`         | 대체 커버(제목 첫 글자)                               |
| `genres`        | 뒷면의 장르 줄만 빠집니다                             |
| `note`          | 뒷면의 이유 줄만 빠집니다                             |
| `listenUrl`     | 듣기 링크만 빠집니다                                  |
| `album`, `year` | 뒷면 머리 줄에서 해당 표기만 빠집니다                 |
