# Side B Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 좋아하는 노래·앨범을 정사각형 커버 카드로 보여 주는 `/side-b`·`/en/side-b` 페이지를 만든다. 카드는 대각선으로 뒤집히고 마우스를 따라 기울어지며, 위쪽 장르 칩으로 거를 수 있다. 관리자 `/admin/side-b`에서 편집한다.

**Architecture:** 데이터는 `src/config/music.ts`의 `MUSIC` 선언에 둔다. 관리자는 기존 범용 코드 생성기(`writeDeclaration`)로 이 선언만 다시 쓴다. 장르 수집과 링크 판정은 alias 없는 순수 모듈 `src/lib/music.ts`에 두고 사이트·관리자 서버·관리자 클라이언트가 함께 쓴다. 페이지 전용 스크립트 `src/scripts/side-b.ts`가 뒤집기·기울기·필터를 담당하며 Side B 페이지에서만 로드된다.

**Tech Stack:** Astro 7.2.4, TypeScript 6.0.3, `astro:assets` `<Image>`, Node 24 내장 `node --test`(TS 타입 제거 실행), 관리자 콘솔(`admin/`, Vite 미들웨어).

**Spec:** `docs/superpowers/specs/2026-10-29-side-b-design.md` — 실행자는 이 계획과 함께 반드시 읽는다. 수치·문구의 근거는 스펙이다.

## Global Constraints

- 화면 문자열은 전부 `src/config/i18n.ts`의 `UI` 사전(ko·en 양쪽)을 거친다. 내부 링크는 `i18n(Astro.url).href()`를 거친다.
- `DESIGN.md`는 수정하지 않는다. 새 토큰이 필요하면 `src/styles/global.css`에 `[local extension]` 주석을 달아 추가한다.
- 헤더(`SiteHeader.astro`, `src/config/site.ts`의 `navOrder`)는 수정하지 않는다.
- 다른 페이지의 JS 번들에 바이트를 추가하지 않는다. anime.js를 새로 쓰지 않는다.
- 런타임 fetch·서버·외부 API·iframe 임베드를 쓰지 않는다.
- 데이터를 창작하지 않는다. `MUSIC`의 최종 커밋 값은 `[]`이고, 검증용 픽스처는 끝나면 지운다.
- 기울기 최대 6°, 빛 반사 없음. 뒤집기 `rotate3d(1, -1, 0, 180deg)`, 0.7s `cubic-bezier(.2,.7,.2,1)`. 기울기 복귀 0.25s ease-out.
- `prefers-reduced-motion: reduce`이면 기울기 없음, 뒤집기·필터 페이드 즉시 전환.
- 버튼 press에 `scale()`을 쓰지 않는다. 히트 영역은 44px 이상, 대비는 라이트·다크 모두 WCAG AA.
- 이유(`note`)는 언어별 최대 140자. 그리드 `repeat(auto-fill, minmax(260px, 1fr))`. 뒷면 장르 칩은 최대 3개 표시.
- 관리자 페이지는 `src/config/*`를 import하지 않는다(`src/lib/music.ts`는 config를 import하지 않으므로 허용).
- 관리자 코드는 `admin/` 아래에만 둔다. 4겹 배제 게이트를 우회하지 않는다.
- 커밋은 하지 않는다. 사용자가 요청할 때만 한다.
- dev 서버를 켠 채 `admin/server/**`나 `src/config/music.ts` 스키마를 바꾸면 반드시 서버를 껐다 켠다(CLAUDE.md 2026-08-26 재시작 규칙).

## Review Focus

1. **커버 파일이 없는 항목**: 커버를 지정하지 않았거나 파일이 사라져도 빌드가 죽지 않고 대체 커버가 나와야 한다. 테스트는 Task 3 Step 2의 픽스처 D.
2. **한쪽 언어만 채운 이유**: `{ ko: '', en: '...' }`이면 한국어 화면에 영어 이유가 나와야 한다. 빈 단락이 나오면 안 된다. Task 3 Step 2의 픽스처 B.
3. **대소문자·공백만 다른 장르**: `Indie Rock`과 ` indie rock`은 칩 하나다. 주소 해시도 하나다. Task 1 테스트 `collectGenres merges case/space variants`.
4. **스킴 없는 듣기 링크·위험한 스킴**: `open.spotify.com/x`는 `https://`가 붙고, `javascript:alert(1)`은 관리자 저장에서 거절된다. Task 1 테스트와 Task 6 Step 4.
5. **관리자에서 커버를 교체한 뒤 저장**: 옛 파일은 `src/assets/side-b/`에서 지워지고, 다른 항목이 쓰는 파일은 남아야 한다. Task 6 Step 4.

```ts
test('genreKey trims and lowercases', () => {
  assert.equal(genreKey('  Indie Rock '), 'indie rock');
});
test('collectGenres merges case/space variants', () => {
  assert.deepEqual(collectGenres([['Indie Rock', 'R&B'], [' indie rock'], ['Jazz', 'R&B', '']]), [
    { key: 'indie rock', label: 'Indie Rock', count: 2 },
    { key: 'r&b', label: 'R&B', count: 2 },
    { key: 'jazz', label: 'Jazz', count: 1 },
  ]);
});
test('collectGenres counts a genre once per card', () => {
  assert.equal(collectGenres([['Jazz', 'jazz']])[0].count, 1);
});
test('genre hash round-trips Korean and symbols', () => {
  for (const key of ['r&b', '발라드', 'k-pop', 'indie rock']) {
    assert.equal(parseGenreHash('#' + genreHash(key)), key);
  }
  assert.equal(parseGenreHash('#genre=%E0%A4%A'), null);
  assert.equal(parseGenreHash('#other=1'), null);
  assert.equal(parseGenreHash(''), null);
});
test('listenService by host', () => {
  assert.equal(listenService('https://www.youtube.com/watch?v=x'), 'youtube');
  assert.equal(listenService('https://youtu.be/x'), 'youtube');
  assert.equal(listenService('https://music.youtube.com/watch?v=x'), 'youtube-music');
  assert.equal(listenService('https://open.spotify.com/track/x'), 'spotify');
  assert.equal(listenService('https://music.apple.com/kr/album/x'), 'apple-music');
  assert.equal(listenService('https://www.melon.com/song/detail.htm?songId=1'), 'melon');
  assert.equal(listenService('https://example.com/x'), null);
  assert.equal(listenService('not a url'), null);
});
test('normalizeListenUrl', () => {
  assert.equal(normalizeListenUrl('  '), undefined);
  assert.equal(normalizeListenUrl('open.spotify.com/track/x'), 'https://open.spotify.com/track/x');
  assert.equal(normalizeListenUrl('//youtu.be/x'), 'https://youtu.be/x');
  assert.equal(normalizeListenUrl('http://example.com/a'), 'http://example.com/a');
  assert.equal(normalizeListenUrl('javascript:alert(1)'), null);
  assert.equal(normalizeListenUrl('mailto:a@b.c'), null);
});
```

  8. 260px 폭(뷰포트 폭을 조절해 카드 260px 상태)에서 A 뒷면의 `scrollHeight <= clientHeight`다.
